## Problema

El fixture `client` en `tests/test_audit_api.py` mockeaba `engine._vector_memory._embed = lambda _text: None`, reemplazando lógica interna del método de embedding en lugar de mockear la capa de red (HTTP a Ollama).

## Cambios

**Solo `tests/test_audit_api.py`** — ningún archivo de producción modificado.

| Antes | Después |
|-------|---------|
| `engine._vector_memory._embed = lambda _text: None` | `monkeypatch.setattr(httpx, "post", lambda **kw: _FakeEmbeddingResponse())` |
| Mock de método interno | Mock de HTTP (`httpx.post`) |

### Añadido: `_FakeEmbeddingResponse`
Clase con atributo `status_code` y método `.json()` — justo lo que `_embed` usa.

### Conservado: LLM mock
`MagicMock` sobre `llm.generate` — mock de red hacia model-router/Ollama. Permitido.

### Documentado: bug DELETE
- `test_delete_non_existent_conversation`: comentario sobre que `routes.py:207` retorna 200 en vez de 404
- `test_delete_same_conversation_twice`: mismo bug documentado

### Crash test: sin cambios
`test_engine_crash_on_init_retries` crea engine roto real (SQLite cerrado). La excepción `ProgrammingError` ocurre en `get_or_create`, antes de que `_embed` sea invocado.
