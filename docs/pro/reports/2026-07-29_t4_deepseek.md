### `_call_openrouter()` → `_call_deepseek()`
- Lee `DEEPSEEK_API_KEY` del `.env` del proyecto (`grep|cut|tr|xargs`) + env var fallback
- POST a `https://api.deepseek.com/chat/completions`
- Modelo: `deepseek-coder`
- Timeout: 180s
- Verifica `[ -s "$outfile" ] && return 0`

### Pipeline de ejecución
| Orden | LLM | Condición |
|-------|-----|-----------|
| 1º | DeepSeek | Intento principal |
| 2º | Ollama (fallback) | Solo si DeepSeek falla, devuelve vacío o < 500 bytes |
| — | exit 1 | Solo si ambos fallan |

### Sin `exit 1` en fallo de DeepSeek
Fallo de DeepSeek → warning en stderr + fallback a Ollama.
`exit 1` solo si ambos (DeepSeek + Ollama) fallan.

### Sin dependencia de `motor.core.secrets`
`motor.core.secrets` retorna placeholder ("placeholder_generar_") mientras que `.env` tiene la key real.
