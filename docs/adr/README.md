# Architecture Decision Records (ADR)

Cada decision arquitectonica importante se documenta aqui.

## Formato

- `docs/adr/NNNN-titulo-corto.md`
- Estado: Propuesto / Aceptado / Rechazado / Obsoleto
- Contexto, Decision, Consecuencias
