# Cola de pendientes de fase

Los pendientes de un plan pueden posponerse (cola) sin bloquear el avance a
la siguiente fase, PERO la fase NO se cierra hasta que la cola esté resuelta
o justificada por Ramón. Cada fila: TASK | pendiente | fecha | estado | resolución.
