## Descripción

Implementar el sistema de orquestación/supervisión multi-nodo: 3 OpenCodes (GX10 Desktop, GX10 Web, Mac)
trabajan en paralelo sin riesgo de sobreescritura, con detección de caídas, resolución automática de
bloqueos y visión unificada.

Arquitectura: **sin NFS** (SPOF+latencia), **API-centric** (orquestador GX10:4097 como punto de verdad).

### Principios (5 reglas de oro)
1. **No shared storage**: los nodos nunca escriben en FS compartido; estado → API del orquestador.
2. **Escritura atómica local**: si la API no responde, el nodo escribe `/tmp/ura_status_<node>.json`.
3. **Archivos de respuesta separados**: supervisor y nodo nunca escriben el mismo archivo (via API).
4. **Heartbeat obligatorio**: cada 60s; si no hay latido en 120s → nodo "CAÍDO".
5. **Auto-resolución de bloqueos**: tras 15 min sin intervención humana → rollback seguro a `main` + stash.
